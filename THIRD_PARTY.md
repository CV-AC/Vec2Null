# Third-party sources

The baseline implementation in `main.py` and `method/approaches`, `method/configs`, `method/dataset`, `method/models`, `method/engine.py`, `method/metrics.py`, `method/mia.py`, and `method/utils.py` derives from [MetaUnlearn / ONE-SHUI](https://github.com/tdemin16/one-shui), by Thomas De Min, Massimiliano Mancini, Stéphane Lathuilière, Subhankar Roy, and Elisa Ricci. The source revision used for comparison is [`24782dc6e1288c960491960ff0c7f999333e7f62`](https://github.com/tdemin16/one-shui/tree/24782dc6e1288c960491960ff0c7f999333e7f62). That revision does not include a license file. Attribution does not establish redistribution permission.

The optional alignment preparation script retrieves `scrfd.py` and `face_align.py` from [InsightFace](https://github.com/deepinsight/insightface) at revision [`0159b24d44cbc91abbd07b7a6fab0ba923a7fddf`](https://github.com/deepinsight/insightface/tree/0159b24d44cbc91abbd07b7a6fab0ba923a7fddf). Source files are kept with the upstream README in `external/insightface`. The upstream source headers are preserved. Code, pretrained detector weights, and training data may have different distribution terms; consult the upstream documentation for each artifact.
